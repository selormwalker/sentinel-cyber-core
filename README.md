# Sentinel Cyber Core

An advanced automated cybersecurity vulnerability scanner.

## Features
- **Header Analysis**: Scans for missing or misconfigured security headers (XSS, HSTS, CSP).
- **Port Scanning**: Identifies open ports and services.
- **AI Explanations**: Uses LLMs to explain vulnerabilities and suggest remediations.

## Setup
1. `pip install -r requirements.txt`
2. `python sentinel/main.py scan <url>`
